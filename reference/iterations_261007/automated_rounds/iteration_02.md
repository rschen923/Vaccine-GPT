## 合题与架构增量

Enforce v1 protein-only input; version v2 DNA windows and mark unclassified windows as unknown; keep Evo2 execution behind a WSL2/CUDA and target-genome validation gate.

## 可证伪假设与检测器

On held-out genomes, compare Evo2 window embeddings against a simple sequence-composition/annotation baseline for prespecified regulatory/gene-element labels.
