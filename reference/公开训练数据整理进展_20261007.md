# VaccineGPT 公开训练数据整理进展（2026-10-07）

## 范围与结论

本批整理了 BacFITBase v1、DEG 必需基因注释、*Pseudomonas aeruginosa* GOLD 基准、SecReT6 T6SS 数据、T3SEpp T3SS 效应蛋白分类基准、AntigenDB 抗原证据、*Streptococcus pneumoniae* CRISPRi-TnSeq 论文中的必需靶基因证据、IEDB 细菌来源抗原聚合记录，以及一个经核验后排除的 OGEE 镜像。原始文件均保留；17 个规范化 JSONL 共检查 399,715 条记录，逐行通过 JSON 解析和标签形状检查。没有把未测样本、未列出的基因或算法预测候选转成阴性，也没有把连续适应度分数伪装成二元必需性标签。

这代表数据整理取得进展，不代表 M2 已可训练或已经验证生物学预测能力。公开数据中的终点并不等价：宿主感染适应度、必需基因、T6SS 效应蛋白和疫苗保护必须分别建模。

- 原始文件清单、SHA-256、来源 URL、许可状态及访问失败记录：`VaccineGPT/data/metadata/public_training_sources_manifest_20261007.json`。
- 处理脚本：`VaccineGPT/scripts/prepare_public_candidate_sources.py`。
- 规范化数据和逐来源审计：仓库外保留数据树 `..\data\processed\public_training_sources_20261007_055028\`，其中 `source_audit.json` 记录原始文件摘要、缺失值、重复、各文件摘要及逐条检查结果。
- 原始压缩包/FASTA/工作簿保存在 `..\data\raw\public_training_sources\reference_databases\`；本轮脚本只读原始数据。
- T3SEpp 规范化输出为 `t3sepp_training_positive.jsonl`、`t3sepp_training_negative.jsonl` 和 `t3sepp_independent_test.jsonl`；精确序列无拆分间重叠，但这不等同于同源簇或物种层级的泄漏排除。
- AntigenDB 归档已通过固定 GitHub commit 下载并校验；规范化索引为 `antigendb_curated_antigen_evidence.jsonl`。归档自身还含 GenBank 记录文件，本轮未抽取或重分发这些序列。GitHub 仓库的 MIT 许可针对软件；README 引用的 AntigenDB 论文数据许可为 CC BY-NC 2.5 UK，因此数据仅按非商业研究材料记录，第三方序列权利仍需逐源核实。
- CRISPRi-TnSeq 的 Supplementary Table 2 与 CC BY 4.0 全文 XML 已存于原始数据目录，并规范化为 `crispri_tnseq_spneumoniae_h4_targets.jsonl`。只抽取靶基因及 IPTG 条件；没有把作者用于遗传互作分析的 positive/negative GI 标签错当成必需/非必需标签。
- IEDB 数据来自官方 IQ-API `antigen_search` 端点；原始两页 JSON 响应及含查询参数、请求范围、精确总数、时间戳与 SHA-256 的 `query_manifest.json` 保存在 `..\data\raw\public_training_sources\reference_databases\IEDB\`，规范化文件为 `iedb_bacterial_antigen_search.jsonl`。复核 17 个 JSONL、399,715 条记录均可解析且 label 形状为 null 或 0/1；IEDB 17,109 条均为 null，不产生保护阳性/阴性。该端点返回的是聚合抗原/assay/参考文献信息，不是一个疫苗保护实验终点统一的监督数据集。
- IEDB 页面仅确认 API 可公开查询；本次未确认数据再利用许可条款。保留来源归属、查询和哈希记录，限制再分发，直至许可得到核实。
- BacFITBase 与 DEG 的下载页没有找到可独立核实的明确数据再使用许可；SecReT6 下载页也未找到明确的 CC 许可。已记录来源和许可状态，但在解决许可问题前应限制传播或再分发。PLOS GOLD 补充表按论文 CC BY 4.0 标注。
- AntigenDB 首次下载超时，随后从固定 GitHub commit 成功取得 16,095,824 字节归档；PLM-Effector（500,907 字节）下载超时，当前没有可用的完整本地数据集，未解包、未写入规范化数据集。

## 对 M2 与跨物种迁移的判断

**目前不应启动统一的 M2 分类训练。** H4 目前是正例集合，没有同实验、同条件下经过充分检测的可靠阴性；H1 是感染适应度连续终点；SecReT6 是 T6SS 效应蛋白证据；T3SEpp 是 Type III effector 序列分类基准；AntigenDB 汇集的是异质研究中报告的抗原，存在明确非保护性条目且保护实验终点并不统一。后三类可作为各自端点的辅助任务/候选证据，但不能冒充疫苗保护标签，也不能与 H1/H4 拼成一个“有效/无效”二元标签。T3SEpp 的 EIB202 截短构建体阴性必须保持在蛋白构建体层级，不能倒推完整基因或全长蛋白阴性。IEDB 中的 assay 结果同样需按实验终点拆分，不能用抗原或表位记录代替体内保护结局。

M1 与 M2 可以分开训练：M1 可使用经过去冗余和分类学整理的跨菌种序列/蛋白组；M2 在 H1–H4 各终点有明确数据合同后，分别使用相应监督数据。跨菌种方案可作为待验证设计：共享表示 + 革兰氏类别或系统发育分支适配头 + EIB202 校准头；验证时按属留出，并按序列同源簇分组，防止近缘菌株泄漏。属内保守性只应作为可消融的输入特征或弱先验，不是必需性标签；只有在留属测试中产生稳定增益后才纳入默认模型。

EIB202 后续补数的优先级是：H4 条件特异的 Tn-seq/CRISPRi 及覆盖度、重复性和对照；H2 有免疫接种—攻毒、适当对照并报告生存/菌负荷等保护终点；H3 关注 EIB202 实验验证的分泌效应与感染表型。跨菌株的基因/蛋白对应必须经序列和位点交叉核验，不得改写成 EIB202 实测。
