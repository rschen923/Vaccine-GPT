# NSFC project design

Convert the review into one testable central scientific question. Define
three to four aims, each with hypothesis, input, method, measurable endpoint,
decision criterion, expected result, risk, and fallback.

The proposal must connect:

`scientific gap → central hypothesis → aims → experiments → analysis → innovation`

For each experiment specify biological material, controls, replicates,
randomization/blocking, sample-size rationale, sequencing depth or assay
budget, quality control, and stopping criteria. Separate discovery experiments
from validation experiments and computational prediction from experimental
causality.

Budget tables should list unit cost, quantity, subtotal, and assumptions. Include
personnel time, sequencing, library preparation, culture/strain handling,
computing/storage, validation assays, and contingency. Do not claim exact
institutional prices; label local quotations as variables.
