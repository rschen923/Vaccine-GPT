# Academic report, PPT and figure generation

## Markdown

Use a stable title, abstract, keywords, methods, results/evidence, limitations,
conclusion, references, and appendices. Include machine-readable tables where
possible and keep figure captions self-contained.

## Figures

Prefer Mermaid for architecture and workflow diagrams, SVG for vector
schematics, and PNG at 300 dpi for raster plots. Every figure has a source,
version, legend, units, and an uncertainty note. Use consistent colors for
M1/M2, data provenance, and evidence tiers.

## Slides

Use one idea per slide: problem, gap, hypothesis, system design, data,
experiments, risks, milestones, budget, and expected impact. Avoid copying
paragraphs from Markdown. Generate a speaker note or caption for every chart.

## QA

Check broken links, missing references, empty figures, unreadable labels,
unresolved placeholders, unsupported claims, and that all generated files are
listed in a manifest.
